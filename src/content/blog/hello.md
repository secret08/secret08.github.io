写东西这件事，最大的敌人不是没灵感，是平台。

公众号会改规则，博客园会限流，语雀会涨价，收藏夹里的链接会 404。你写了三年的东西，可能因为对方一次业务调整就没了。

所以我把内容搬回自己手里：Markdown 文件存在 GitHub 仓库里，网站用 Astro 编译成纯静态 HTML，托管在 CDN 上。整套东西没有数据库、没有服务器、没有月费。

## 这个站长什么样

- **导航页**：所有常用网站一目了然
- **博客**：长文章，慢慢写
- **说说**：一句话的心情和碎片，不用凑成一篇文章
- **收藏区**：一部分链接单独收在这里

技术上只有一个约束：**不能用 VPS**。所以整条链路都是 serverless 的——静态文件由边缘节点直出，需要动态能力的地方用边缘函数，数据留在自己手上。

## 评论为什么不用插件

大部分博客评论系统都有个共同问题：数据在别人服务器上。哪天服务关停，评论区就变成一片空白。

这个站用 giscus，评论其实是 GitHub Discussions 里的一条条讨论。好处是：

1. 数据永远在 GitHub，不会消失
2. 有 GitHub 账号才能留言，天然挡掉广告
3. 我可以定期把有意思的问答摘进正文——评论区不再只是"楼下聊天"，而是文章的一部分

第 3 点是我最看重的。一条评论如果只是躺在最底下，三年后没人会翻到；但如果它被整理进正文，就变成了文章的一部分，跟着文章一起被搜索到。
